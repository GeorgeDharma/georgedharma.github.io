Professional workshop · F05

Signing off a dual-currency portfolio after a split and a replayed dividend

A custodian sends overlapping price and cash feeds for a small euro-reporting portfolio. The controller needs a defensible 30 September close using only information received before 16:00 UTC, a day return and a list of exceptions. A corrected quote arrives the next morning and a dollar dividend appears twice in the raw feed. Build the production logic on the given records and supply independent checks. Positions, cash and external flows are exact in this teaching case. All stated times are UTC.

InputsWalkthroughReconciled exhibitCompleted documentYour turn
Your role
Investment operations and performance analyst
What to submit
A portfolio NAV sign-off, a working Python implementation, return attribution and a control memorandum explaining the treatment of corrected quotes, duplicate transaction IDs and end-of-day contributions. NAV means net asset value, the euro value of holdings plus cash here.

From inputs to decision

01

Fix the valuation perimeter and timing

Separating event date from receipt time prevents a later correction from leaking into the historical report. The contribution’s timing determines the return denominator.

  1. Assign the A and B price publications to the 30 September valuation date while storing their actual UTC receipt times. Accept only receipts strictly before 16:00 on 30 September. For each security order eligible versions by arrival and choose the most recent.
  2. Construct opening NAV directly from custody. A is 10 × USD 10 × 0.90 = €90, B is 4 × €25 = €100, and cash is €50. Opening net asset value is €240. No investor cash arrives inside the holding interval.

Opening denominator €240. The historical cutoff and end-of-period flow convention are recorded in the report manifest.

02

Apply the corporate action before pricing

Share count and per-share price change jointly in a split. A per-share drop from USD 10 to USD 5.50 would exaggerate a loss if share count stayed at ten.

  1. The two-for-one split makes 20 A shares. There is no cash from the split itself. The declared dividend of USD 0.10 per new share implies gross dividend USD 2.00, providing a separate entitlement check on the D1 cash record.
  2. B stays at four shares. With eligible closing price USD 5.50 and €0.92/USD, A’s closing euro position is €101.20. B uses €24.00, giving €96.00. The €24.50 corrected price arrived the next day.

Closing equity positions total €197.20. Keep a trace to the 15:59 A quote, the 15:55 B quote and corporate action S1.

03

Resolve stable event identities before translating or summing

A cash transaction can be delivered more than once after a network retry. Summing duplicates before checking identity overstates the investor’s entitlement and hides the real exception.

  1. Group by stable event ID and compare currency, amount and event type. Both D1 messages are identical, so post one USD 2 dividend converted at 0.92 = €1.84. A later D1 with an altered amount would be quarantined as a conflict pending the correction protocol.
  2. Post the fee of −€1 and the external contribution of +€10 once each. Cash is €50 + €1.84 − €1 + €10 = €60.84, matching the separately supplied custodian balance. Raw cash-message count is four and valid unique events number three.

Cash control difference €0.00. Record one identical replay as an operational exception with no second posting.

04

Build the end-of-day NAV and return

Changes caused by market performance, distributions or fees belong to return. Money subscribed by the client forms part of ending NAV but should not create reported investment gain.

  1. Closing NAV = €101.20 + €96.00 + €60.84 = €258.04. The overall change versus €240 is €18.04. Remove the €10 external closing contribution to obtain investment gain €8.04.
  2. Daily total return = €8.04/€240 = 3.35%. Check with components independent of the NAV subtraction. A market/FX gain €11.20, B market loss €4.00, dividend €1.84 and fee −€1.00 sum to €8.04.

Report closing NAV €258.04 and net investment return 3.35%, with €10 separate client financing flow.

05

Reproduce the result in Python

A short executable reference implementation gives the controller a way to trace the event and quote choices, independent of a production dashboard.

  1. Run the following as one Python 3 script. It uses UTC-aware date selection, exact decimal amounts and a conflicting-replay check.

    from datetime import datetime
from decimal import Decimal as D
def instant(s):
    return datetime.fromisoformat(s.replace("Z", "+00:00"))
cutoff = instant("2026-09-30T16:00:00Z")
quotes = [("A","2026-09-30T15:30:00Z","5.40"), ("A","2026-09-30T15:59:00Z","5.50"), ("B","2026-09-30T15:55:00Z","24.00"), ("B","2026-10-01T08:00:00Z","24.50")]
def closing_price(asset):
    eligible = [r for r in quotes if r[0] == asset and instant(r[1]) < cutoff]
    if not eligible:
        raise ValueError("Missing eligible quote for " + asset)
    return D(max(eligible, key=lambda r: instant(r[1]))[2])
events = [("D1","USD","2","income"), ("D1","USD","2","income"), ("F1","EUR","-1","fee"), ("C1","EUR","10","external")]
ledger = {}
for event_id, currency, amount, kind in events:
    record = (currency, D(amount), kind)
    if event_id in ledger and ledger[event_id] != record:
        raise ValueError("Conflicting event " + event_id)
    ledger[event_id] = record
rates = {"USD": D("0.92"), "EUR": D("1")}
cash = D("50") + sum(amount * rates[ccy] for ccy, amount, kind in ledger.values())
external = sum(amount * rates[ccy] for ccy, amount, kind in ledger.values() if kind == "external")
units_a = 10 * 2
assert ledger["D1"][1] == units_a * D("0.10")
nav = units_a * closing_price("A") * rates["USD"] + 4 * closing_price("B") + cash
pnl = nav - D("240") - external
daily = pnl / D("240")
assert (len(ledger), cash, nav, pnl, daily) == (3, D("60.84"), D("258.04"), D("8.04"), D("0.0335"))
print(nav, cash, pnl, daily)
  2. The example provides a single valuation date, unique timestamps per asset and one corporate-action row. A production run should also key by instrument identity and economic date, define tie-breaking for identical timestamps, and check the expected source constituents before processing.

The assertions validate materially different controls, including dividend entitlement, unique event count, cash, NAV, P&L and the decimal return.

06

Investigate the corrected quote and duplicate counterfactuals

Management may see a later vendor screen and ask why the earlier NAV differs. Explain differences in a new reporting vintage while preserving the historical snapshot.

  1. At the next-day correction, B at €24.50 would add 4 × €0.50 = €2 to the historical economic-date value if a restatement were formally requested. Restated NAV would be €260.04 and restated performance €10.04/€240 ≈ 4.1833%. The signed point-in-time close still uses €24.00.
  2. If D1 had been posted twice, cash would increase incorrectly by another €1.84 to €62.68, creating an independent cash reconciliation error. NAV would also be €1.84 too high. Correcting the replay changes neither the declared dividend nor the genuine investment strategy.

Log the B correction as a later version and the second D1 message as a replay. They have different causes and remediation paths.

07

Sign off and preserve the evidence

A self-consistent spreadsheet can still use future quotes or bad identities. The control pack should let another analyst reproduce the actual 16:00 decision and its sources.

  1. Save exact input bytes and stable checksums, quote receipt and valuation dates, corporate action version S1, FX quote direction, code revision and return timing convention. Archive the output’s contributing price and event identifiers.
  2. Obtain separate custodian cash and position confirmations, and verify units 20 and four against the split notice. State that the report uses zero transaction fees beyond the stated €1 and no extra withholding tax. Document that conflicting event versions or a missing eligible quote block sign-off under this case’s control rules.

The investment controller can release the 30 September report with zero cash-control difference and a full audit trail for the two identified source exceptions.

Daily valuation sign-off to the investment controller

Released valuation

The 30 September 16:00 UTC close is €258.04. The €10 client contribution is reported separately and the daily fee-net total return is 3.35%. The position and cash movement attribution reproduces the €8.04 investment gain.

Corporate action and currency

Applied the two-for-one A split before valuing twenty shares at USD 5.50. The USD 2 dividend agrees with twenty entitlements of USD 0.10. Closing conversion used €0.92 per dollar for the share position and the cash distribution.

Exceptions and resolution

One identical D1 replay was detected and excluded. The B correction at 08:00 UTC the following day falls outside the 16:00 source cutoff. Preserve it for restatement review. A formally revised historical valuation would rise by €2, while the original decision snapshot remains reproducible.

Control conclusion

Custodian cash of €60.84 and verified closing units of 20 A and 4 B agree with the reconstruction. Retain raw files, selected versions, eligible timestamps, the stable transaction list, code record and signed calculation. Task 1

If the B correction is formally accepted into a later reporting vintage for 30 September, what fee-net return should the revised report show?

B rises €2 in value. Closing NAV becomes €260.04 and investment gain €260.04 − €240 − €10 = €10.04. Divide by €240 for approximately 4.1833%. The original point-in-time report still has its 3.35% return.

Task 2

Holding the original eligible B quote fixed, what closing NAV results if the correct closing dollar rate had been €0.90 per USD instead of €0.92?

See the full solution

A would be 20 × USD 5.50 × 0.90 = €99. Its USD 2 dividend converts to €1.80. Cash becomes €50 + €1.80 − €1 + €10 = €60.80. Add B at €96 to reach €255.80.

Task 3

Suppose B has no eligible quote and its per-share value can only be bounded between €22 and €26. What is the lower bound on the original daily portfolio return under that sensitivity?

See the full solution

Use the original FX, cash and A value. At €22 the four B shares are €88. NAV is €101.20 + €88 + €60.84 = €250.04. Net of opening €240 and external €10, the gain is €0.04, or approximately 0.01667% of €240. This bounds return under the assumed prices; it does not create an observed price.

Use a stable event ID and compare all economically relevant fields on duplicate records. Identical ID, currency, amount and type leave the booked balance unchanged.
